CS-360 Event Tracker — Android App Artifact (Software Design & Engineering)

Overview

The Event Tracker application was originally developed in CS-360: Mobile Architecture and Programming as a simple Android app that allowed users to create and store event reminders. For my Software Design & Engineering enhancement in the CS-499 capstone, I selected this project because it provided a strong foundation for demonstrating professional-level architectural design, mobile development skills, and best practices for maintainable software. The enhanced revision reflects modern Android development principles and transforms the academic prototype into an application that follows industry-aligned patterns and standards.

Original Artifact (Before Enhancement)

The original CS-360 version of the app functioned correctly but was structured more like an academic exercise than a production-ready mobile application. Several architectural limitations existed, including:

  • Business logic placed directly inside Activities
  • No architectural pattern (e.g., MVVM)
  • Minimal separation between UI, logic, and data handling
  • No persistent storage beyond temporary in-memory lists
  • Limited error handling and validation
  • Very few comments or documentation for maintainability

Although the app worked, it was not scalable or maintainable in its initial form, making it an ideal candidate for enhancement in the Software Design & Engineering category.

Final Enhanced Artifact — CS-499 Submission

As part of my capstone enhancements, I redesigned the Event Tracker using a professional, scalable architecture. The updated project demonstrates industry-standard software engineering principles and significantly improves clarity, structure, and long-term maintainability.

  • Implemented MVVM Architecture — Introduced ViewModel classes to remove logic from Activities, improved separation of concerns, and made the app more testable.
  • Added Room Database — Created Event, EventDao, and EventDatabase to support true persistent local storage using SQLite through the Room ORM.
  • Introduced Repository Pattern — Simplified data access logic by providing a unified interface between the ViewModel and Room, preparing the project for future integration with remote APIs.
  • Improved UI/UX with RecyclerView — Events now display in a structured, scrollable list using a custom EventAdapter, offering a cleaner and more intuitive user interface.
  • Added WorkManager Scaffold — Implemented background-processing structure to demonstrate readiness for scheduled notifications or syncing workflows.
  • Added Detailed Comments and Documentation — Included class-level and method-level comments, greatly improving readability for instructors, peers, and potential employers.

These changes elevate the application from a basic class assignment to a professionally structured mobile application suitable for inclusion in a technical portfolio.

CS-499 Outcomes Demonstrated

Outcome 1 — Design and Evaluate Computing Solutions: By restructuring the application using MVVM, Room, and the Repository pattern, I demonstrated the ability to design scalable mobile software and evaluate trade-offs in architecture, performance, and maintainability.

Outcome 2 — Professional Communication: The enhanced project includes comprehensive in-code comments, clear documentation, and an organized file structure that communicates design intent effectively to technical audiences.

Outcome 4 — Apply Industry Tools and Techniques: I incorporated Android development tools such as LiveData, RecyclerView, ViewModel, WorkManager, and Room. These enhancements align with best practices used in modern mobile applications and demonstrate proficiency with real-world development frameworks.

Reflection

Enhancing this artifact allowed me to experience firsthand how much architectural choices impact the quality of an application. Through redesigning the app, I learned how MVVM improves maintainability, how Room provides reliable long-term storage, and how structured components make testing and feature expansion far easier. This enhancement not only strengthened my Android development skills but also reinforced core software engineering principles such as modularity, documentation, scalability, and security-minded design.

This artifact now reflects the professional standards expected in the software development industry and demonstrates my readiness to design maintainable, user-focused applications in future mobile or full-stack development roles.
