Video Narrative

My CS-499 video presentation is a code review of my original artifacts before any enhancements were completed. In the video, I walk through the initial versions of my three projects—CS-360 Event Tracker, CS-210 Corner Grocer, and CS-340 Grazioso Salvare. I explain how each artifact worked originally, point out areas that needed improvement, and discuss weaknesses in design, structure, performance, and security.

The purpose of this review was to identify enhancement opportunities aligned with the CS-499 outcomes. I outlined how I planned to redesign the Event Tracker using MVVM, how I intended to introduce advanced data structures into Corner Grocer, and how I would improve CRUD security and error handling in Grazioso Salvare. This demonstrates my ability to analyze existing code, communicate improvement strategies, and plan enhancements that increase software quality, efficiency, and maintainability.
