#  CS-360 Event Tracker — Enhanced Android App

## Overview
Originally built in **CS-360: Mobile Architecture and Programming**, this Android app allows users to create and manage personal events.  
For my **CS-499 Capstone**, I enhanced it to demonstrate professional-level software engineering practices.

---

## Enhancements
- Implemented **MVVM architecture** for clean separation of concerns  
- Added **Room database** for persistent event storage  
- Introduced **Repository layer** for scalable data handling  
- Improved **UI/UX** with card layouts and validation  
- Added **WorkManager** scaffold for background processing  

---

## Outcomes Demonstrated
- **Outcome 4:** Applied modern techniques (MVVM, Room, Repository) to deliver value  
- **Outcome 2:** Produced professional documentation and readable code  

---

## Reflection
This enhancement helped me understand how architecture impacts reliability and maintainability.  
It transformed a classroom project into a production-style Android app ready for real-world use.
